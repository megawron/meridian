# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in Meridian (such as HTML/WebKit rendering bypasses, remote content leaks, or credential handling issues), please **do not** open a public issue.

Instead, please report it confidentially using one of the following channels:

- **Email**: [martin@martingawron.com](mailto:martin@martingawron.com)
- **GitHub Security Advisories**: [Report a vulnerability privately](https://github.com/megawron/meridian/security/advisories/new)

Please include steps to reproduce the issue and confirm that it affects the latest version of Meridian.
