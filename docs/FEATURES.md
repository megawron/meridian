# Features

Meridian brings mail, calendars, contacts, tasks, and memos together in a single application.

## Mail

- Support for multiple accounts (IMAP, Exchange, Google, and local folders) through GNOME Online Accounts and Evolution Data Server.
- Three-pane layout with folder tree, message list, and reading pane.
- Conversation threading, unread and starred filters, labels, and search.
- HTML and plain-text message viewing with remote image blocking for privacy.
- Rich text and plain-text composer with attachments, inline images, signatures, and contact autocomplete.

## Calendar

- Day, Work Week, Week, Month, Year, and Agenda views.
- Support for multiple local and online calendars with custom colors.
- Recurring events, reminders, categories, time zones, and meeting invitations.
- Optional side-by-side task and memo panel right next to your schedule.

## Contacts

- Multiple local and synced address books (CardDAV, Exchange, Google Contacts).
- Card and list views with fast search, contact editing, and vCard import/export.

## Tasks & Memos

- Dedicated to-do lists with due dates, priorities, and completion tracking.
- Built-in notes and memos synced across your accounts.

## Desktop Integration

- Native GNOME interface with automatic light and dark mode support.
- Customizable keyboard shortcuts and window layout.
