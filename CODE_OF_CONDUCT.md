# Code of Conduct

Meridian aims to be a welcoming, friendly, and harassment-free project for everyone.

We follow the principles of the [GNOME Code of Conduct](https://conduct.gnome.org/):

- **Be friendly and patient.** Remember that people use different setups, have different backgrounds, and contribute in their spare time.
- **Be respectful and constructive.** Disagreements and bug reports are normal, but critique should always focus on the technical problem, never on the person.
- **Be considerate.** Keep in mind that this project is maintained in good faith and provided free of charge.

Unacceptable behavior such as personal attacks, harassment, or trolling will not be tolerated in issues, pull requests, or discussions.
